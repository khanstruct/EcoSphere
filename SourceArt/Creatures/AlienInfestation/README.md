## Placement

The intended host sphere center is at image coordinates (50% width, 60% height measured from the top), with diameter approximately 70% of the canvas width. The sprite uses a custom Unity pivot (0.5, 0.4), measured from bottom-left, to place that host center at the sphere's transform. Display sprite canvas width at approximately sphere diameter / 0.70, multiplied by the modifier's alienScale (currently 1.25). Runtime shader brightness/outline and a pulsing host rim make infestation visible at gameplay scale without changing the source sprite. Keep it camera-facing. This is a single visual overlay, not collision geometry. True dynamic front/back depth would require split layers; the supplied art uses painted foreshortening and transparent gaps to suggest the wrap in one sprite. The infestation modifier now uses this overlay in gameplay. Infested state, matching exclusions, attachment-adjacency cleansing, breakaway removal, alien-hit sound and nearest-edge red escape streaks are implemented through shared board/modifier logic.
